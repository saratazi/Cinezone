🎬 Cinezone

link: https://saratazi.github.io/Cinezone

A modern and responsive movie website where users can discover, search, and explore movies.

✨ Features

- 🔍 Search for movies
- 🎬 Browse popular and trending movies
- 📖 View movie details
- 📱 Responsive design
- 🌙 Modern and clean UI
- ⚡ Fast and easy to use

🛠️ Technologies

- HTML
- CSS
- JavaScript

🚀 Getting Started

1. Clone the repository:
   
   git clone https://github.com/saratazi/cinezone.git

2. Open the project folder.

3. Open "index.html" in your browser: saratazi.github.io/Cinezone.
